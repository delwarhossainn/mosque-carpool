# 🕌 Mosque Carpool — Winnipeg

A carpool app connecting Muslim drivers with riders heading to mosques
across Winnipeg. Brothers are matched with brothers, sisters with sisters.
Riders never see drivers until one accepts their request.

## How it works

- **Riders** pick a mosque → the nearest online driver going there gets the
  request → on accept, the rider sees the driver's name, car, ETA and a
  4-digit pickup code.
- **Drivers** tap Go Online, pick their mosque, and accept/decline incoming
  requests.
- 14 verified Winnipeg mosques ship with the app.
